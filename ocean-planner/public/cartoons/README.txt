Drop her cartoon images in this folder using these exact file names.
Square PNG (or transparent PNG), around 512 x 512 px works best.

  welcome.png  - shown next to the app title (e.g. smiling / waving)
  added.png    - pops up when she adds a task (e.g. thumbs up / writing)
  done.png     - pops up when she finishes a task (e.g. happy / cheering)
  goal.png     - pops up when a week or month goal reaches 100% (biggest celebration)
  empty.png    - shown on empty screens (e.g. relaxing / sleeping)

Until a file exists, a dashed rose placeholder is shown instead.
To use a different file name, edit src/lib/cartoons.ts.
